# example — chandler for glow lab

glow lab is a made-up skincare brand. this folder shows the three files chandler
loads, filled in for a real-ish business, so you can see what "not blank" looks
like.

- `rules.md` — glow lab's hard limits (a skincare brand has real compliance ones)
- `context.md` — who glow lab is and who it sells to
- `chandler.md` — the task file: how chandler writes for glow lab specifically

swap the details for your own and you've got your first agent.
